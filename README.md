# qa-demo-api

Tiny product API used by `qa-demo-app` (demo project for the AI Dev Platform QA gate).

- `npm start` — listens on `PORT` (default 3001), prints `API listening on <port>`
- `npm test` — `node --test`
- `GET /api/products`, `GET /health`

No dependencies: Node's `http` and `node:test` only.
